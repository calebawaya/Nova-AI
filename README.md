# Nova AI

Nova AI is a simple AI-style assistant built with HTML, CSS, JavaScript and Python.

## Languages
- HTML — interface
- CSS — design
- JavaScript — browser chat
- Python — backend API

## Run the Python backend

Install the packages:

```bash
pip install -r requirements.txt
```

Start Nova AI:

```python
python app.py
```

The API runs at `http://127.0.0.1:5000`.

> GitHub Pages can host the HTML/CSS/JavaScript frontend, but it cannot run the Python Flask server. The Python backend needs a Python-capable hosting service when we deploy it online.
